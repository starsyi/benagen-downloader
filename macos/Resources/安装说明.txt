Benagen 数据下载工具 —— macOS 安装说明
=====================================

第 1 步  把 BenagenDownloader 拖进右边的「Applications（应用程序）」文件夹。

第 2 步  打开「访达 → 应用程序」，找到 BenagenDownloader，**右键点它 → 选「打开」**
        （或按住 Control 点它 → 打开），在弹窗里再点一次「打开」。

        为什么要右键：这个应用没有 Apple 付费证书，直接双击会被系统拦一次；
        右键「打开」等于告诉系统「这个我认了」，点过一次以后就不用再点了。

第 3 步（只有出现「已损坏，无法打开」或「无法验证开发者」时才需要）
        本条最稳，照做一定能过：

        a) 把这个「已损坏修复.command」用鼠标拖到左边侧栏的「下载」（Downloads）里，
           也就是拷到 ~/Downloads；
        b) 打开「终端」（启动台里搜 终端 / Terminal）；
        c) 在终端窗口里粘贴下面这一行，回车 ——

           bash ~/Downloads/已损坏修复.command

        d) 脚本会问开机密码（输入时屏幕上不显示，敲完直接回车）。
           它会把应用装进「应用程序」、清掉系统加的隔离标记，然后启动。

        注意：跑之前请让安装盘（.dmg）保持挂载状态 —— 脚本要到挂载的盘里
        去取应用。忘了也没关系，它会提示你怎么做。

        这也行（更省事，但要会右键）：直接在盘里的 .command 上右键 → 打开 → 再点「打开」。

常见问题
--------
Q: 提示「已损坏」是不是下载坏了？
A: 不是。文件通常是完整的，只是系统没认出签名者。按第 2/3 步处理即可。

Q: 每次打开都要右键吗？
A: 不用。成功打开过一次之后，以后双击即可。

Q: Linux / Windows 用哪个？
A: Windows 用 BenagenDownloader-0.3.0-Windows-x86_64.exe；Linux / 服务器用
   benagen-dl-0.3.0-linux-x86_64（命令行，先 chmod +x）。
