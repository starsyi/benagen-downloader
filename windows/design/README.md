# A0 视觉样张

## 怎么打开（**必须走本地服务，不能双击**）
双击打开是 `file://` 协议，而 Chrome/Edge 在 `file://` 下会以 CORS **拦掉字体加载**
（安全策略，与我们无关）。被拦掉之后页面会用系统字体渲染 —— 看上去"也能看"，
但你**没有**看到真正的字体，而字体是观感的一部分。

    cd <仓库根目录>
    python3 -m http.server 8000
    # 然后打开 http://localhost:8000/windows/design/a0-proof.html

⚠️ **字体真的加载上了**：Network 里必须有一条 `ui-subset.otf` 且状态 **200**。
**这一条待人类伙伴验。**

## 这是什么
主界面首屏的**静态**样张：侧边栏 + 工具栏 + 文件表格 + 一条常驻提示行。
没有服务、没有 JS、没有任何业务逻辑 —— 它不是一个能跑的软件，是一张能交互的图。

## 已知偏离（**照搬 macOS 观感**这件事上，这六处是估的/另造的/有意不做的）
1. **字体**：样张用 `@font-face` 加载了**交付版同一份 CJK 子集**
   （`../assets/ui-subset.otf`）⇒ **中文与交付版逐字同款**（这正是"必须走本地服务"的
   第二个理由：`file://` 下字体被 CORS 拦掉，页面会静默回退到本机字体，看着"也能看"，
   但那不是交付的样子）。
   唯一差别是**西文**：规格 §9.2 把 Inter 子集排在阶段 A，所以这里西文走 Noto 的拉丁字形，
   而交付版第一顺位是 Inter。它落地时只改 `--font-ui` 一行。
2. **侧边栏底色 `--bg-sidebar`**：macOS 由系统材质给出，Web 没有对应物（清点 §9）。
   这是全表唯一一处另造的颜色。
3. **行高 28px**：macOS 侧是 `List` 的系统默认值，源码里没有这个数（清点 §9）。
4. **`.caption` 档的 10px**：macOS 的 10pt 有亚像素抗锯齿撑住。**本机是 macOS，
   验不了 Windows 上的实际表现** —— 这一档是本次样张最需要你拿主意的地方。
5. **侧边栏半透明（`backdrop-filter`）有意不做**：规格 §7.3 点名要复刻它，
   但在这张布局里它是**空操作** —— 侧边栏是本页最左一列，下面没有别的内容可透
   （窗口底色是纯白，透出来还是白）。macOS 那边它有意义是因为窗口背后是桌面壁纸。
   ⇒ 本样张用 `--bg-sidebar` 的**实色**近似。**阶段 A 重看这一条**：若那时工具栏/
   侧边栏底下真的会滚过内容（比如长列表），它才有意义。
   ⚠️ **不要**为了"规格里写了"就贴一个看不出效果的属性上去 —— 那会让人以为它被验过了。
6. **选中行里「状态」那一列丢了它的语义色** —— **这一条要你拍板**。
   `.row.is-selected` 下有三条覆盖规则把 `.col-size` / `.col-time` / `.col-state`
   统一压成 `rgba(255,255,255,.75)`。所以你选中的那一行，`已完成` 显示的是**白色**而不是绿色。
   - **为什么这么写**：macOS 那边状态色是 `foregroundStyle(tint(color))` **显式**给的，
     选中行上很可能**仍然是绿的** —— 也就是**绿字压在蓝底上**，对比度很差。
     本样张选了"可读优先"。
   - **但这是一处偏离，而且我没有把握**：SwiftUI 的 `List` 选中态究竟会不会盖掉显式
     `foregroundStyle`，**我没有实测**（要跑 macOS 客户端才能看）。
   - ⇒ **请你对着这一处拿个主意**：要"可读优先"（现在这样），还是"严格照搬 macOS"
     （删掉那三条覆盖规则，看绿字压蓝底能不能接受）。两条都行，**我要的是你的判断**。
